  <action>
Add the following methods to `CaptionModel`:

1. `_inject_names(image, english_caption, known_faces)` — orchestrator:
   - Try grounding-based injection first via `_ground_caption_to_faces()`
   - If substitutions found, apply via `_apply_name_substitutions()`
   - Fallback: `_apply_positional_substitution()` if grounding fails
   - Wrap in try/except: on any error, log warning and return original caption

2. `_ground_caption_to_faces(image, english_caption, known_faces)` → dict of substitutions:
   - Call `self.florence.run_task(image, "<CAPTION_TO_PHRASE_GROUNDING>", english_caption)`
   - Florence-2 returns `{"bboxes": [...], "labels": [...]}`
   - For each grounded phrase+bbox, compute IoU with each known_faces bbox
   - If IoU > 0.3, map phrase → name in substitution dict
   - Return substitution dict (may be empty)

3. `_apply_name_substitutions(caption, substitutions)` → str:
   - For each (phrase, name) pair, replace phrase in caption with name

4. `_apply_positional_substitution(caption, known_faces)` → str:
   - Define PERSON_PATTERNS list: "a man", "the man", "a woman", "the woman", "a person", "the person", etc.
   - Replace first occurrence of each pattern with next name from known_faces list (left-to-right)
   - Case-insensitive matching

5. `_compute_iou(bbox_a, bbox_b)` → float:
   - Standard Intersection over Union for two [x1,y1,x2,y2] bounding boxes
   - Guard against zero-area (return 0.0)

6. Update `get_context_comprehensive()` to call `_inject_names()` when known_faces is provided and non-empty, BEFORE translation step (so translated text includes names).
  </action>
