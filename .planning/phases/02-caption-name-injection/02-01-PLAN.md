  <action>
Create `python-worker/models/caption_model.py` with class `CaptionModel`:

Constructor: `__init__(self, florence_model, translation_model)` — receives shared instances (no model loading).

Public methods:
1. `get_context_comprehensive(image, known_faces=None)` — accepts `known_faces` but ignores it in this plan (wired in 02-02). Steps:
   - Call `_generate_caption(image)` → English caption string
   - Call `_translate_to_short_phrase(english_caption)` → short Indonesian phrase (≤10 words)
   - Call `_translate_to_description(english_caption)` → full Indonesian paragraph
   - Call `_extract_detailed_elements(english_caption.lower())` → elements dict
   - Return `{english_caption, indonesian_phrase, indonesian_description, elements}`

2. `detect_school_age(caption, face_ages=None)` — copy VERBATIM from BLIPModel including:
   - AGE_KEYWORDS dict, UNIFORM_COLORS dict
   - _detect_school_age_from_caption(), _classify_age_group(), _detect_uniform_color()
   - Priority chain: uniform color → face age → caption keyword

3. `get_model_info()` → metadata dict

Private methods:
- `_generate_caption(image)` → calls `self.florence.run_task(image, "<MORE_DETAILED_CAPTION>")`, extracts string. Fallback: "An image"
- `_translate_to_short_phrase(english_caption)` → takes first sentence (split on `.`) or first 15 words, translates, truncates to ≤10 words
- `_translate_to_description(english_caption)` → takes full caption (max 3 sentences), translates to Indonesian
- `_extract_detailed_elements(caption)` → copy verbatim from BLIPModel: `_extract_people_info`, `_extract_activity`, `_extract_setting`, `_extract_objects`, `_extract_mood`. These are keyword-based heuristics that work on any English caption.

Elements dict shape (must match exactly):
```python
{
    "people": {"count": int, "count_indonesian": str},
    "activity": {"english": str, "indonesian": str},
    "setting": {"english": str, "indonesian": str},
    "objects": {"english": List[str], "indonesian": List[str]},
    "mood": str
}
```

Error handling: Florence-2 failure → fallback caption "An image". Translation failure → use English as-is. Element extraction failure → return defaults.
