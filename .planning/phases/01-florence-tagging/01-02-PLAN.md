  <action>
1. Add `timm` and `einops` to requirements.txt (unpinned, required by Florence-2 vision backbone).

2. Create `python-worker/models/florence_model.py` with class `FlorenceModel`:
   - `MODEL_NAME = "microsoft/Florence-2-base"`
   - `__init__(translation_model, device_type="cpu", threshold=0.25, top_k=10, language="id")` — stores all params, calls `_load_model()`. `threshold` is kept for API compat but unused by Florence-2.
   - `_load_model()` → loads `AutoProcessor` + `AutoModelForCausalLM` with `trust_remote_code=True`, calls `model.eval()`
   - `run_task(image, task, text_input="")` → **PUBLIC method** (no underscore). Runs a Florence-2 task: builds prompt, processes with processor, generates with `max_new_tokens=1024, num_beams=3`, batch_decodes, post_processes. Returns parsed result dict.
   - `get_tags(image, threshold=None, top_k=None, language=None)` → runs `<OD>` + `<DENSE_REGION_CAPTION>`, merges labels into deduplicated list, caps at top_k, translates to Indonesian if language="id". Returns `List[str]`. On error returns `[]`.
   - `get_objects(image, threshold=0.20, top_k=15)` → runs `<OD>`, deduplicates labels (lowercase), caps at top_k. Returns `List[str]`. On error returns `[]`.
   - `get_model_info()` → returns model metadata dict

IMPORTANT: `run_task()` must be PUBLIC (no underscore prefix) because CaptionModel in Phase 2 needs to call it to run `<MORE_DETAILED_CAPTION>` and `<CAPTION_TO_PHRASE_GROUNDING>` tasks.

Risk mitigation: If `transformers==4.36.0` fails to load Florence-2, bump to `transformers>=4.40.0` in requirements.txt.
  </action>
