1. Add `sentencepiece` to requirements.txt after the `transformers` line (unpinned — no known conflicts with transformers==4.36.0).

2. Create `python-worker/models/translation_model.py` with class `TranslationModel`:
   - `MODEL_NAME = "Helsinki-NLP/opus-mt-en-id"`
   - `__init__()` → calls `_load_model()` which loads `MarianTokenizer` + `MarianMTModel` from pretrained, calls `model.eval()`
   - `translate(text: str) -> str` → delegates to `translate_batch([text])[0]`, returns original text if empty/whitespace
   - `translate_batch(texts: List[str]) -> List[str]` → tokenizes with `padding=True, truncation=True, max_length=512`, generates, batch_decodes with `skip_special_tokens=True`. On error: logs and returns original English strings (graceful degradation).
   - `get_model_info() -> dict` → returns model metadata dict

Key decisions:
- CPU-only (no device parameter) — MarianMT is small and fast on CPU
- Batch-first design — Florence produces multiple labels; one forward pass is ~5x faster than looping
- Graceful degradation on error — return original English strings, never crash
- max_length=512 — prevents OOM on unexpectedly long inputs
  </action>
